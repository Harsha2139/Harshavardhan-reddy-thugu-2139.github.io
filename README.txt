# Thugu Harshavardhan Reddy — Portfolio

## Files
- index.html — portfolio structure
- style.css — complete responsive styling
- script.js — mobile menu, back-to-top button and year
- profile.jpg — uploaded profile image

## Run locally
Open `index.html` in a browser.

## GitHub Pages
1. Create a repository or use your existing portfolio repository.
2. Upload `index.html`, `style.css`, `script.js`, and `profile.jpg`.
3. Commit the files.
4. Enable GitHub Pages from repository Settings → Pages.
5. Select the branch containing the files and save.

## Notes
The portfolio uses only the information provided by the student.
Add genuine certifications, achievements and additional project links as they become available.
